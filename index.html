YOUR WALLET, YOUR NUMBERS

Update your limits

GitHub handles sign-in and edit permissions. Only accounts with write access can change the published limits.

  1. Open the limits file on GitHub.
  2. Change the pool’s amount in rupees, without commas.
  3. Update the date, then commit to the publishing branch.

Example: "hdfc": 349000
Updates Millennia and Regalia Gold together.

Refresh after the GitHub Pages deployment succeeds.
