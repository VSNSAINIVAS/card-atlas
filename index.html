OWNER ACCESS

Update your limits

GitHub handles sign-in and edit permissions. Only accounts with write access to your repository can change the published limits.

  1. Open the limits file on GitHub.
  2. Change the relevant pool’s amount in rupees, without commas.
  3. Update the date, then commit to the publishing branch.

Example: "hdfc": 349000
Updates Millennia and Regalia Gold together.

Publication usually takes a few minutes. Refresh after the GitHub Pages deployment succeeds.
